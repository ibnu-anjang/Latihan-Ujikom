Section 01 / System Design

Arsitektur Desain & Filament UI System

Traceability: Exact 1:1

Pembagian Aktor Sistem

1. Publik (Client Web) Akses informasi profil perusahaan, tracking tarif estimasi, melihat display kesiapan armada, dan katalog layanan.
2. Petugas Admin Operasional Akses login Filament untuk mengelola status pengiriman barang, logistik armada, master layanan, dan personel staf.

Menghindari AI Slop pada UI

UI generik buatan AI sering kali menggunakan ikon emoji yang tidak konsisten dan ornamen dekoratif yang mustahil diimplementasikan. Desain ini secara ketat menggunakan Heroicons SVG bawaan Filament, palet warna Tailwind netral (Zinc & Slate), dan komponen fungsional yang ada pada controller Laravel.

Prinsip Ergonomi Panel:

Navigasi terfokus pada efisiensi kerja operator gudang: tabel data dengan density optimal, input form berbasis modal dialog cepat, dan indikator status berkode warna.
